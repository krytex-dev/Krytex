🔐 Krytex Bot — Privacy Policy

Last Updated: 10 February 2026

This Privacy Policy explains how Krytex Bot ("Krytex", "the Bot") collects, uses, and protects data while operating on Discord.

📊 Data We Collect

Krytex Bot may store the following data:

  • User IDs
  • Server (Guild) IDs
  • Channel IDs
  • Role IDs
  • Moderation records (warnings, mutes, bans)
  • Ticket system data
  • Command usage data
⚠️ Krytex Bot does not read or store private messages (DMs), except for system notifications or moderation-related messages.

🎯 Why We Collect Data

Collected data is used strictly to:

  • Provide core bot functionality
  • Maintain moderation logs
  • Improve performance and reliability
  • Protect servers from abuse and attacks

🔒 Data Security

  • Data is securely stored
  • Access is limited to authorized developers only
  • No data is sold, traded, or shared with third parties

🗂 Data Retention

Data is retained only as long as necessary. Server-related data may be removed after the bot is removed from a server.

🧑‍⚖️ User Rights

Server owners may request:

  • Data removal (where applicable)
  • Information about stored data
  • Privacy-related clarifications

🔗 Third-Party Services

Krytex Bot operates using Discord’s API and follows:

  • Discord Terms of Service
  • Discord Privacy Policy
