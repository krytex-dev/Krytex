🔐 Krytex Bot — Privacy Policy

Last Updated: 10 February 2026

This Privacy Policy explains how Krytex Bot collects, uses, and protects data while operating on Discord.

📊 Data We Collect

  • User IDs
  • Server IDs
  • Channel IDs
  • Role IDs
  • Moderation records (warnings, mutes, bans)
  • Ticket system data
  • Command usage data

Note: Krytex Bot does not read or store private messages (DMs), except for system notifications or moderation actions.

🎯 Why We Collect Data

  • Provide core bot functionality
  • Maintain moderation logs
  • Improve performance and security
  • Protect servers from abuse

🔒 Data Security

  • Secure data storage
  • Restricted developer access
  • No selling or sharing of data

🗂 Data Retention

Data is retained only as long as necessary. Server-related data may be deleted after the bot is removed.

🧑‍⚖️ User Rights

  • Request data removal (where applicable)
  • Request information about stored data
  • Request privacy clarifications

🔗 Third-Party Services

Krytex Bot operates under Discord’s API and complies with:

  • Discord Terms of Service
  • Discord Privacy Policy
