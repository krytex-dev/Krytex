# 🔐 Krytex Bot — Privacy Policy

_Last Updated: 10 February 2026_

This document explains how Krytex Bot collects and uses data.

---

## 🔹 Data We Collect
Krytex Bot may store:

- User IDs
- Server IDs
- Channel IDs
- Role IDs
- Moderation records (warnings, mutes, bans)
- Ticket system data
- Command usage data

> ⚠️ Krytex Bot does **not** read or store private messages (DMs),
> except for system or moderation notifications.

---

## 🔹 Why We Collect Data
Data is used strictly to:
- Provide bot functionality
- Maintain moderation logs
- Improve performance and security
- Protect servers from abuse

---

## 🔹 Data Security
- Data is securely stored
- Access is restricted to authorized developers
- No data is sold or shared with third parties

---

## 🔹 Data Retention
Data is kept only as long as required.
Server data may be deleted after the bot is removed.

---

## 🔹 User Rights
Server owners may request:
- Data removal (where applicable)
- Information on stored data
- Privacy clarifications

---

## 🔹 Third-Party Services
Krytex Bot operates under Discord’s API and follows:
- Discord Terms of Service
- Discord Privacy Policy
